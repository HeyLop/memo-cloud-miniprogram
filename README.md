# 清单备忘 · Memo Cloud

一个备忘录 + 工作提醒微信小程序。数据存云端、跨设备同步，可凭分享码只读分享给他人。

## 功能一览

- 微信一键登录（主）+ WorkBuddy 账号登录（备用）
- 备忘的增删改查：标题、正文、分类、优先级、截止时间、完成勾选
- 首页今日提醒：到期/逾期未完成项置顶高亮
- 分类筛选：工作 / 个人 / 学习 / 其他
- 分享码：生成 10 位码，对方凭码只读查看快照

## 技术栈

原生微信小程序（WXML/WXSS/JS）+ WorkBuddy 云服务（PostgreSQL + Auth + RLS）。
无服务端代码，小程序端不持有密钥。

## 快速开始

```bash
npm install          # 安装云 SDK（@tencent-ai/workbuddy-cloud-sdk）
# 用微信开发者工具或 WorkBuddy 应用卡预览打开本项目
```

配置位：`utils/config.js` 的 `SUBSCRIBE_TEMPLATE_IDS`（订阅消息模板 ID，留空则只做 App 内提醒）。
云端配置在 `utils/cloud.js`，随应用发布保留。

## 当前状态与限制

见 [05-待办与已知限制](docs/05-待办与已知限制.md)。要点：
- 微信主动推送暂未实现（平台无定时触发能力），只做 App 内提醒
- 分享是只读快照，非实时协作
- 真机登录/云端读写尚未验证（H5 预览无法替代）
