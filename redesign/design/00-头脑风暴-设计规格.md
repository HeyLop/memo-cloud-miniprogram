## 2. 产品定义

**一句话**：一个能"想到就记、到点必达、工作生活两不扰"的个人待办小程序。

**目标用户**：本人（单人使用），重度记录、怕漏事、工作与个人事务混杂。

**四层闭环**（D3 拆解）：

```
极速记录 → 工作生活分区 → 今日聚焦 → 可靠提醒
 (输入)       (组织)         (呈现)       (输出)
```

- **极速记录**：首页常驻输入框，一句话录入，**本地正则解析**（D12，原 D7 云函数 NLP 降二期）自动抽取时间与分区。输入"明天下午3点交报告"→ 解析出 dueAt=明天15:00、zone=工作、title=交报告。目标 3 秒完成一条记录。解析失败时降级为手工补选时间（不丢数据）。
- **工作生活分区**：两条独立时间线/视图，**双色主题**（D9：工作=蓝色系、生活=暖色系），切换时导航栏/背景/强调色整体变化。各自的通知时段不同（D8）。
- **今日聚焦**：首页只显示今天该做的少数几件事，自动按优先级+截止时间排序，其余折叠。分区视图下各自聚焦本区。
- **可靠提醒（本版降级为 App 内，D11）**：首页"今日聚焦"区聚合到期/逾期事项，工作/生活分区各自高亮。**微信订阅消息推送降为二期**——订阅消息仍需正式 AppID + 模板（测试号做不到），本版不阻断。分区时段规则（D8 设计）保留，二期实现时直接复用。

## 3. 技术方案（基于 D10 修订：保留 WorkBuddy 云）

| 前端 | 原生小程序（WXML/WXSS/JS） | 沿用原生路线，不上框架 |

**关键技术决策**：

- 智能解析（D7）可用 WorkBuddy 云的 LLM 模块实现，无需自建 NLP 服务。
- 前端只做展示与交互，不碰任何服务端凭证。

## 7. 三项决策的实现规格（已确认，供实施计划直接使用）

### 7.1 智能解析（D7）

- **触发**：首页输入框提交一句话 → 调 `utils/parse-todo.js` 的 `parseTodo()`（D12 本版本地实现）。
- **本版职责**：本地正则从文本抽取 `dueAt`（时间）、`zone`（继承当前分区）、`title`（去掉时间词后的事项）。
  - 时间解析：识别"今天/明天/后天/周X + 上午/下午/晚上 + 时刻"；时段修正（下午3点→15点、晚上12点→次日0点）。
  - 兜底：解析失败 → 返回 `needsManual: true`，编辑页弹时间选择器补选，原文保留为 title。
  - 二期增强：云端 LLM 解析复杂表达（凭证云端），失败再回落正则。
- **输出**：`{ title, dueAt, zone, confidence, needsManual }`。
- **前端**：解析结果先以"草稿卡片"展示，用户确认/微调后才入库——避免解析错误直接写脏数据。
- **验收**：输入"明天下午3点交报告"能在草稿卡显示正确时间与"工作"分区；输入无法解析的文本时能降级手工补选且不丢字。

### 7.2 提醒策略（D8 设计保留 / D11 本版降级，推送二期实现）

> ⚠️ 以下推送逻辑为**二期规格**。本版（v2-first）只实现 App 内今日提醒，不实现订阅消息推送。保留此规格供二期直接复用。

- **两级**：每条待办最多两次推送——`dueAt - 1天`（提前提醒）与 `dueAt`（到期提醒）。
- **分时段**：
  - 工作区（zone=work）：仅在工作时段推送，默认工作日 09:00-18:00；非工作时段到期的，改到下一工作日 09:00 推。
  - 生活区（zone=life）：仅在晚间/周末推送，默认工作日 18:00-22:00 + 周末全天。
  - 时段参数存 `users.settings.workHours`，用户可配置。
- **防重复**：`todos.remindSent` 记录已发的 `{stage, sentAt}`，云函数发送前检查，同一 stage 只发一次。
- **订阅授权**：首次保存带时间的待办时请求订阅消息授权；未授权则只做 App 内提醒，不阻断其他功能。
- **云函数定时**：每分钟扫描 `dueAt` 落在推送窗口内的未完成待办，按规则发送。
- **验收**：造一条工作区明天到期的待办，提前提醒只在工作时段发出；同一条不会重复收到第二次。

### 7.3 界面风格（D9）

- **双色主题**：
  - 工作区：蓝色系（主色 #1769E0，背景 #F5F8FF）
  - 生活区：暖色系（主色 #D9730D，背景 #FFF8F0）
- **切换联动**：切换分区视图时，导航栏、页面背景、按钮、徽章、强调色整体切换；用 CSS 变量统一定义两套主题 token，页面只引用变量。
- **结构**：顶部分区切换（工作/生活）→ 今日聚焦卡 → 待办列表 → 底部极速输入栏。
- **验收**：切换分区时全页面配色随之改变；两区同一套组件，仅主题变量不同。
