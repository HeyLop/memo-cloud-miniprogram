## 1. 总体架构

```
┌─────────────────────────────────────────────┐
│  微信小程序（原生 WXML/WXSS/JS）              │
│  ├─ pages/index    首页：登录 + 今日提醒 + 列表 │
│  ├─ pages/edit     编辑页：新建/编辑/删除       │
│  └─ pages/shared   共享页：凭码只读查看         │
│         ↓ 调用                                │
│  utils/notes-store.js  业务数据层（CRUD/分享）  │
│  utils/cloud.js        云服务客户端单例        │
│  utils/config.js       可配置项（模板 ID）      │
└──────────────────┬──────────────────────────┘
                   │ HTTPS / SDK
┌──────────────────▼──────────────────────────┐
│  WorkBuddy 云服务                             │
│  ├─ Auth    账号（WorkBuddy / 微信两种登录）    │
│  ├─ Database  PostgreSQL（notes / notes_share）│
│  └─ RLS     按 owner_id 行级隔离              │
└─────────────────────────────────────────────┘
```

关键约束：**小程序端不持有任何服务端密钥**。云端配置（endpoint、publishableKey、OAuth clientId）都是可公开的客户端标识。真正的权限靠 RLS 在服务端强制，不靠前端判断。

## 3. 数据模型

### 3.1 `notes`（主表，用户私有）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT IDENTITY | 主键 |
| `owner_id` | TEXT | 所有者，`DEFAULT auth.uid()`，RLS 隔离依据 |
| `title` | TEXT | 标题（必填） |
| `content` | TEXT | 正文（纯文本） |
| `category` | TEXT | 分类，默认「工作」 |
| `priority` | TEXT | 优先级「高/普通/低」，默认「普通」 |
| `due_at` | TIMESTAMPTZ | 截止时间，可空 |
| `done` | BOOLEAN | 完成状态，默认 false |
| `share_token` | TEXT | 已生成的分享码，可空 |
| `text` | TEXT | 兼容早期 demo 的旧字段，代码写入时同步 `= title` |
| `created_at` / `updated_at` | TIMESTAMPTZ | 时间戳 |

RLS 策略：select / insert / update / delete 四条，均以 `owner_id = auth.uid()` 约束。

### 3.2 `notes_share`（分享快照表）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT IDENTITY | 主键 |
| `owner_id` | TEXT | 创建者 |
| `token` | TEXT UNIQUE | 10 位随机分享码 |
| `title/content/category/priority/due_at/done` | 同 notes | 生成时点的快照 |

RLS 策略：**select 公开可读**（`USING (true)`，凭码即可看），insert/update/delete 仅 owner。

> 数据迁移方式：所有建表/加列用幂等语句（`CREATE TABLE IF NOT EXISTS`、`ADD COLUMN IF NOT EXISTS`），重复执行安全。

## 4. 页面与状态机

### 4.1 首页 `pages/index`

三种认证状态由一个变量驱动（`index.wxml`）：

```
checking ──有会话──> signed-in ──> 加载并展示列表
   │                     │
   └──无会话──> signed-out   └─退出登录─> signed-out
                   │
        ┌──────────┴──────────┐
   微信一键登录(主)      WorkBuddy 登录(备用)
```

数据加载：`loadNotes()` 调 `notes.list()` → 每条经 `decorate()` 注入 `priorityClass`（ASCII 类名）→ 分出 `todayNotes`（今天到期或逾期且未完成）。

### 4.2 编辑页 `pages/edit`

- `onLoad(options.id)`：有 id 则拉取列表找对应项回填（含 ISO 时间拆成日期+时间）；无 id 为新建。
- `onSave()`：校验标题 → 组装 `dueAt`（`YYYY-MM-DDTHH:mm:ss+08:00`）→ create/update → 成功后若有截止时间则请求订阅授权。
- `onDelete()`：二次确认 → remove。

### 4.3 共享页 `pages/shared`

入参 `options.code` 或用户输入 → `getShared(token)` → 只读渲染。错误走失败态，不显示任何内容。

## 5. 关键流程时序

**微信登录（FR-1.1）**
```
用户点按钮 → wx.login({success}) → 拿到 code
  → wx.getAccountInfoSync().miniProgram.appId 取运行时 appid
  → cloud.auth.signInWithWechat(code, appid)
  → 成功: session.user 写入 data，loadNotes()
  → 失败: 显示错误，保持登录页
```
App 侧 `app.js` 的 `onShow` 调 `handleWorkBuddyMiniProgramCallback(options)` 供 WorkBuddy 备用登录回跳使用。

**分享（FR-4.1/4.2）**
```
点分享 → publishShare(note)
  → token = 已有 share_token 或新生成 10 位随机码
  → notes_share 按 token 查：有则 update，无则 insert
  → 回写 notes.share_token → 弹窗展示可复制的码
接收方 → getShared(token) → notes_share 按 token 查 → 只读渲染
```

## 6. 编码约定（踩过坑，务必遵守）

1. **WXSS/WXML 中 class 名与选择器必须 ASCII**。中文只能出现在文本节点和 JS 数据值里。曾因 `.priority-高` 导致发布校验失败（`unexpected ? at pos 4173`）。现在优先级走 `PRIORITY_CLASS` 映射：`高→priority-high`、`普通→priority-normal`、`低→priority-low`。
2. **优先级/分类值本身可以是中文**，只是不能直接当 class 名。
3. **SQL 直连写入用户表必须显式给 `owner_id`**：工具执行 SQL 时没有终端登录身份，`auth.uid()` 为空会触发 NOT NULL 错误。这是 RLS 生效的正常表现，不是 bug。
4. **微信登录 appid 不可硬编码**：试用版与正式版是两套独立小程序。
5. **H5 预览拿不到真实 `wx.login` code**，登录链路只能在真机验证。
6. **发布前跑校验**：`node --check` 全部 JS + JSON 严格解析 + WXSS 中文选择器扫描。
